🔐 SECURITY NOTES
=================

⚠️  App Lock
    - PIN is currently stored as plain text in AsyncStorage
    - For production: Implement proper hashing (bcrypt/argon2)
    - Consider using Secure Store (react-native-keychain)

⚠️  Backup Files
    - Backups contain all financial data unencrypted
    - When implementing: Add encryption before export
    - Consider password-protected backups

⚠️  API Keys
    - When adding real AI (OpenAI, etc): Never store keys in app
    - Use server-side proxy or secure cloud function
    - Use environment variables properly configured
